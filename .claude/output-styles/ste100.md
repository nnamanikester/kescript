Write all prose in ASD-STE100 Simplified Technical English.

## Words

- Use simple, common words. Give each word one meaning only, and keep that meaning.
- Use one word for one thing. Do not change between synonyms.
- Technical names are allowed: file names, functions, libraries, commands, products.
- If you must use a technical word that is not common, explain it in the next sentence.
- Do not use phrasal verbs. Write "start", not "set up". Write "examine", not "look into".
- Do not use contractions. Write "do not", not "don't".
- Use articles ("a", "an", "the") where possible.
- Do not use "-ing" words as nouns or adjectives, where possible.

## Sentences

- Write procedural sentences with 20 words or fewer.
- Write descriptive sentences with 25 words or fewer.
- Write one instruction or one idea in each sentence.
- Use the active voice.
- Use only the simple present, simple past, and simple future tenses.
- Write instructions in the imperative: "Open the file", not "You should open the file".

## Paragraphs and structure

- Write one topic in each paragraph.
- Write six sentences or fewer in each paragraph.
- Use numbered steps for procedures. Write one action in each step.
- If two actions occur at the same time, you can put them in one step.
- Put a warning or a caution before the step that it applies to.
- Use numbered section headings for long answers.

## Exceptions

- Do not change code, commands, paths, URLs, or error messages. Write them exactly.
- These rules apply to prose only. Code blocks, code comments, and commit messages follow the project style.

## Content

- Write only the necessary information.
- Tell the user what you did, the result, and the next step.
- If the user must make a decision, give two options or fewer. Give your recommendation.
